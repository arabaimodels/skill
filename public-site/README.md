# استوديو مهارات سمارت مودلز — واجهة العرض العامة v1.0

## المبدأ
هذه نسخة **عرض للزائر فقط** تحافظ على البنية والألوان وتخطيط المشروع الثلاثي في واجهة V8 الأصلية.
عند فتح الموقع على GitHub Pages، تُقرأ `data/public-catalog.json` تلقائيًا دون استيراد ملف JSON يدويًا.
الصور المنشورة تُحمّل من `assets/published/`، وليست من ذاكرة متصفح الزائر.

## التحديث والنشر
1. **راجع الصور والمحتوى قبل النشر**: رفع الصور إلى مستودع عام يجعلها عامة، وقد تظل متاحة في تاريخ Git حتى بعد حذفها.
2. استخدم مجلد `public-site` فقط، وانسخ **محتوياته** مباشرة إلى جذر مستودع `arabaimodels/skill` (لا تنسخ مجلد `public-site` نفسه).
3. في GitHub Desktop: Changes → Commit to main → Push origin.
4. في GitHub: Settings → Pages → Deploy from a branch → main → /(root) → Save.
5. الرابط المتوقع بعد نجاح النشر: https://arabaimodels.github.io/skill/

## تحديث البيانات مستقبلًا
- احفظ العمل في **الاستوديو الخاص** `skills` وصدّر آخر نسخة `smart-models-all-skills.json`.
- شغّل أداة `private-tools/prepare_publication.py` من الحزمة الخاصة بعد مراجعة الصور والتأكد من التصريح بنشرها.
- يحوّل البرنامج نسخة التصدير إلى فهرس عام وملفات صور منفصلة، ولا ينسخ البرومبتات، أو أسماء النماذج، أو معرّفات الإدارة، أو حقول التعليمات الخاصة.
- راجع التغييرات في GitHub Desktop قبل Commit/Push.

## منع التباس الخصوصية
- **لا ترفع** `smart-models-all-skills.json` إلى المستودع العام.
- **لا ترفع** محتويات `private-tools` إلى المستودع العام.
- أوصاف المهارات الثلاث الناقصة تحمل وسم «وصف تحريري مقترح — يحتاج اعتمادًا» إلى أن تعتمد.
- لم تُفحص ملكية الصور أو موافقات الأشخاص الظاهرين فيها؛ استبعد أي صور غير مصرح بها قبل النشر.
- Google Analytics **معطل افتراضيًا**. لتفعيله بعد مراجعة سياسة الخصوصية غيّر `assets/js/config.js`، واجعل `enabled:true` مع `measurementId` صالح. لن يبدأ القياس إلا عند موافقة الزائر.
- GitHub Pages خدمة نشر ثابت، **لا** يزامن تغييرك في IndexedDB الخاص تلقائيًا إلى الزائر. حدّث بيانات الموقع ثم ارفعها إلى GitHub في كل إصدار.

## تشغيل المعاينة المحلية
داخل `public-site` شغّل `python -m http.server 8766` ثم افتح http://localhost:8766/ ؛ الفتح المباشر عبر `file://` لا يسمح عادة بقراءة JSON بواسطة `fetch`.
