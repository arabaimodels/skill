# سمارت مودلز — واجهة عرض المهارات العامة

**الإصدار:** 1.0.0 — نسخة نشر أولية للمراجعة.

## الوظيفة
واجهة عربية عامة مستقلة عن استوديو الإدارة، تعرض أربع مهارات من بيانات `smart-models-all-skills.json` التي قدمها المستخدم. تعمل دون خادم خلفي على GitHub Pages، مع بحث، تصنيفات، نافذة تفاصيل، روابط تشغيل متى وردت في البيانات، وروابط مشاركة، وتوافق مع الهواتف.

## بنية الملفات

```text
smart-models-skill/
├── index.html
├── assets/
│   ├── css/style.css
│   ├── images/logo.png
│   └── js/
│       ├── catalog.js
│       ├── config.js
│       ├── analytics.js
│       └── app.js
├── START-PREVIEW.bat
└── README.md
```

## التشغيل المحلي
افتح `START-PREVIEW.bat` على Windows، أو نفّذ `python -m http.server 8767` ثم افتح `http://localhost:8767/`. يمكن أيضًا فتح `index.html` مباشرة لأن الفهرس مضمن في `catalog.js` ولا يعتمد على Fetch.

## النشر على GitHub Pages
1. افتح مستودع `smart-models-skill` **العام** المرتبط بGitHub Desktop. **لا تخلط هذا المشروع بمستودع `skills` الخاص.**
2. انسخ **محتويات** مجلد `smart-models-skill` إلى جذر المستودع العام، وليس مجلد `smart-models-skill` بكامله داخل المستودع.
3. راجع `assets/js/catalog.js` واعتمد الأوصاف التحريرية الثلاثة وأضف الروابط الرسمية الناقصة عند توفرها. لا تخترع عناوين URL.
4. في GitHub Desktop نفّذ Commit ثم Push origin.
5. من GitHub: Settings → Pages → Deploy from a branch → `main` و`/(root)` → Save. انتظر ظهور رابط المنشور في إعدادات Pages.
6. حدّث `og:image` في `index.html` إلى رابط HTTPS مطلق للصورة بعد معرفة عنوان Pages النهائي؛ فالرابط النسبي قد لا يعمل في معاينات تطبيقات المشاركة.
7. تأكد من تحميل الموقع في نافذة خاصة وعلى الهاتف، وأن روابطه تعمل.

## قياس الزيارات والتفاعل
يستخدم الموقع واجهة جاهزة لـ Google Analytics 4 **غير مفعّلة افتراضيًا**. لتفعيلها:
1. أنشئ تدفق Web للموقع المنشور في GA4 أو استخدم تدفقًا مصرحًا به.
2. افتح `assets/js/config.js` واضبط `analytics.enabled` على `true`، و`analytics.measurementId` على معرّف `G-...` الصحيح.
3. نفّذ Commit/Push للتعديل بعد اعتماد إشعار الخصوصية.
4. لا يتم تحميل مكتبة Google Analytics قبل اختيار الزائر «أوافق»؛ يسجل `page_view`، و`skill_view`، و`outbound_click`، و`skill_filter`، و`skill_search` (فئة عدد النتائج فقط)، و`share_skill`، دون إرسال نص البحث أو البرومبتات.
5. اختبر التتبع في GA4 DebugView/Realtime؛ لا يعني وجود الأداة أن الزيارات مقاسة قبل التفعيل والقبول.

**تنبيه الخصوصية:** إعداد الموافقة المحلي إيضاحي ولا يُعد بمفرده مراجعة قانونية للامتثال. ينبغي مراجعة سياسة الخصوصية ونطاق الموافقة قبل النشر النهائي.

## ضوابط البيانات
- الفهرس العام مستخلص من **الأسماء والحقول العامة فقط**. لا تُضمَّن فيه محتويات الصور الأصلية ولا صور نتائج المشاريع ولا برومبتات المستخدم ولا المعرّفات الداخلية.
- المهارة الأولى تملك رابط تشغيل ورابط مجتمع موثقين في بيانات المستخدم.
- المهارات الأخرى لا تملك روابط تشغيل في المصدر، لذا تعرض واجهة غير فعالة دون اختلاق روابط.
- الأوصاف الثلاثة الناقصة صيغت **تحريريًا كمقترحات أولية**؛ وتم وسمها صراحةً داخل `catalog.js` والواجهة، ولا يجوز اعتبارها ضوابط تشغيلية معتمدة قبل مراجعتها.
- الصور البيانية داخل بطاقات المهارات رسوم SVG رمزية من هذا المشروع، وليست صور المشاريع أو نتائجها.
- التطبيق العام **قراءة فقط**؛ لا يُنشئ أو ينشر أو يحذف مهارات، وليس مزامنة حية مع قاعدة بيانات استوديو الإدارة.

## التحقق
اختبر فحص HTML وJavaScript، والفتح من `localhost` وعرض النوافذ والبحث والفلاتر والقياسات على الهاتف قبل النشر. **النشر الفعلي والأمان في بيئة GitHub Pages لم يُختبرا بعد**.
